# ESP32 Security System Overview

## Architecture
ESP32-CAM Nodes → Raspberry Pi Gateway → Local AI Detection → Cloud Event Server → Notifications

## Components
- ESP32-CAM camera stations
- Raspberry Pi gateway
- YOLO local detection
- Cloud event storage
- Monitoring and notification system

## Design Goals
- Local AI processing
- Upload only important events
- Wireless device provisioning
- Scalable security network
