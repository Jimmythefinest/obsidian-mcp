# Glove HCI Architecture

## Data Flow
Sensors → ESP32 → BLE/WiFi → Host Computer → Gesture Recognition → Action

## Hardware Layer
- Flex sensors for finger position
- IMU sensors for orientation and movement
- Pressure sensors for grip detection
- ESP32-class microcontroller
- Haptic feedback motors

## Software Layer
- Sensor data acquisition
- Filtering and calibration
- Gesture classification
- Machine learning models for complex gestures
- Command mapping

## Applications
- VR/AR
- Robotics control
- Assistive technology
- Sign language recognition
- Remote manipulation
